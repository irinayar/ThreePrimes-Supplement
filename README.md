# ThreePrimes supplement (programs and recorded outputs)

Exact-integer and decimal check programs with recorded outputs (2026-11-20 and 2026-11-21, America/Phoenix) and a SHA-256 manifest. They support the computer-assisted statements of the ThreePrimes article (working title; versions 2 to 8: explicit upper bounds for the least witness in prime-square balls, `P_p(k) = sup_n ||k/p^(n^2)||`) and replay computer-assisted values of the earlier joint-density work. A matching output is **not** an independent reproduction: all programs were written and run by the same agent family (Claude) as the article; none has been run or reviewed by another author. **The article itself is not part of this repository** (no manuscripts, PDFs or notes).

The Lean modules are not copied here: they are in the public repository irinayar/MyPseudotopology-Lean (`LeanCheck/ThreePrimes*.lean`, note `THREEPRIMES_FORMALIZATION.md`; commits `b9c162c`, `4149424`, `2d82819`, `2966e99`, `309029b`). The programs and outputs of the earlier articles (`ThreePrimePlus_certificates`, `TVGplus_collision_certificates`) are not part of this supplement.

## Requirements and cost
.NET SDK 9 (used: 9.0.306, Windows 11); C#, `System.Numerics.BigInteger` and `Int128`; no other packages. Each program is a console project (`programs/<name>/Program.cs` + `<name>.csproj`). Run a copy outside the synchronized folder to avoid `bin/obj` clutter: copy `programs/<name>` to a temporary directory and run `dotnet run -c Release [-- args]` there. Times below are those of the recorded runs (seconds unless stated); memory use is small (no large arrays; not measured precisely, well under 1 GB). The decisions of every program are made in exact integer arithmetic except where stated (the double-precision steps are only used to form candidate integers, which are then tested exactly).

## Limits
Programs and outputs are finite computations in stated ranges; a matching output verifies the code on that range, not the theorem for all parameters (proofs: article and Lean). The programs have not been audited by a second reader; the validation inside them is brute force on small cases and agreement with the values of v19 and of earlier notes.
